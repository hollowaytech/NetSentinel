# NetSentinel
C++ intrusion detection simulator that analyzes login attempts using parallel arrays and automatically blacklists malicious IPs.
# General Features ⚙️
- Arrays
- If-else statements
- Loops
# Security Features 🔐
- Malicious IP detection
- Blacklisting malicious items
# Default Configurations 📦
- Max capacity (100)
- Attempt limit (20)
- Password (hacker)
